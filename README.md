# informAC

## Informes de resultados de acelerometría para participantes

**Autora:** Verónica Cabanas Sánchez · Universidad Autónoma de Madrid.

Software para generar informes de resultados de acelerometría dirigidos a participantes, a partir de resultados procesados con GGIR. La versión v2.02 incorpora el cálculo del cumplimiento de las recomendaciones de actividad física de la OMS, recomendaciones según el nivel de actividad física y los pasos semanales, y recomendaciones sobre sedentarismo prolongado. Genera informes en formatos HTML y PDF.
